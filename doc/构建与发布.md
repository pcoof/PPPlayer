# 构建与发布（Windows 单文件 exe）

> 本文从 `README.md` 拆出，便于单独维护。返回 [README](../README.md) · [文档索引](README.md)

本项目通过 GitHub Actions（`.github/workflows/build.yml`）自动构建并发布 **Windows 单文件 exe**。

## CI 流程

推送到 `main` 或手动触发 `Build & Release` 工作流即自动执行：

1. `calc-version`：计算版本号 `YYYYMMDD.N`（检索当日最大 Tag 序号 +1）。
2. `update-version-file`：把版本号写回 `pyproject.toml` 的 `[project].version` 与 `main.py` 的版本读取入口（源码不再写死版本号）。
3. `build-package`：在 `windows-latest` 上用 `uv` + PyInstaller 产出单文件 exe（`--onefile --noconsole --icon=logo.ico`），并用 `tools/make_version_info.py` 生成 Windows 版本资源（右键属性可见版本号），再打包为便携 zip 上传 artifact。
4. `compare-version`（构建期版本对比）：对比本地版本与 GitHub 最新 Release，决定是否发布。
5. `release`：生成 CHANGELOG、幂等创建 Git Tag、发布 GitHub Release 并上传全部产物。

产物：`ppplayer.exe`（单文件）与 `ppplayer-portable.zip`（便携包）。

> 版本资源说明：Windows 文件版本的 4 段数值每段须 ≤ 65535，因此 `YYYYMMDD.N` 会拆成 `(年, 月, 日, 序号)` 写入，右键属性「详细信息」可见。

## 本地手动构建（与 CI 等价）

```bash
uv sync --frozen
uv run pyinstaller --onefile --noconsole --icon=logo.ico --name=ppplayer \
  --add-data "static;static" \
  --add-data "pyproject.toml;." \
  --hidden-import clr --hidden-import pythonnet \
  --hidden-import webview.platforms.edgechromium --hidden-import webview.platforms.winforms \
  --hidden-import src --hidden-import src.server --hidden-import src.config_store \
  --hidden-import src.parser.sniffer --hidden-import src.parser.m3u8_filter \
  --hidden-import src.cms --hidden-import src.cms.detector --hidden-import src.cms.base \
  --hidden-import src.cms.apple_cms --hidden-import src.cms.feifei_cms \
  --hidden-import src.cms.haiyang_cms --hidden-import src.cms.endpoint \
  --collect-all pythonnet \
  main.py --noconfirm --clean
```

## 版本来源

应用版本号只从 `pyproject.toml` 的 `[project].version` 读取（回退链：环境变量 `PPPLAYER_VERSION` → `dev`），构建期由 CI 写回，**源码不维护固定版本常量**。

## 应用内自更新

- 启动后后台检查 GitHub 最新 Release；有新版本即后台无感下载，就绪后标题栏出现「更新」入口。
- 下载走「直连 GitHub 优先，失败自动切 `https://cdn.gh-proxy.org/` 镜像」的回退策略（见 [README 功能列表](../README.md#功能)）。
- 点击更新 → 写自删 bat → 当前进程退出 → bat 等旧进程退出（有界等待 + `taskkill` 兜底）→ 覆盖 exe → 重启新版。
- 本地验证开关：`PPPLAYER_FAKE_UPDATE=<下载地址>` + `PPPLAYER_FAKE_VERSION=<版本>` 可在不发真实 Release 的情况下跑通全流程。
- 更新日志：`%TMP%\PPPlayer_update\PPPlayer_update.log`。
